# Security Policy

Security guidance for metaharness lives in [docs/security.md](docs/security.md).

Treat `.harness/` artifacts, provider raw events, diffs, ledgers, prompts, and
transcripts as sensitive. Do not publish credentials or private run artifacts in
issues, pull requests, logs, examples, or generated handoff material.

For vulnerability handling, use the repository owner's private security
reporting channel when one is available. If you are working locally without that
channel, coordinate with maintainers out of band before sharing exploit details
or secrets publicly.
